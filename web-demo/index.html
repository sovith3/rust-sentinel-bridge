Download Install guide
  1. Load the extension — download rust-sentinel-extension.zip, extract it, open chrome://extensions, enable Developer mode → Load unpacked, and pick the extracted folder. Copy the 32-character id.
  2. Register the native host — unzip rust-sentinel-bridge-win64.zip and run powershell -ExecutionPolicy Bypass -File .\install.ps1, then paste the extension id. It only writes to %LOCALAPPDATA% and HKCU.
  3. Reload this page — the badge above turns green as soon as the Rust host answers a PING over the native messaging pipe.
